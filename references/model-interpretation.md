# Model interpretation

## Principle

Formatting rules create a safe floor. The model must still decide what the material means visually. A deck should not look different merely to avoid repetition; its form should reveal a tension, relationship, mechanism, or transformation in the content.

## Interpretation sequence

1. State the thesis without visual language.
2. Identify the central relationship: contrast, sequence, causality, hierarchy, network, threshold, or transformation.
3. Decide whether a metaphor helps. Write `none` and a reason when literal structure is stronger.
4. Choose one or two motifs that can evolve across pages.
5. Plan the reader's emotional and density rhythm.
6. Write one sentence per slide describing what the eye notices first and why.
7. Choose archetypes and primitives only after those decisions.
8. Name familiar habits from recent decks that should not be repeated without meaning.
9. Choose whether the deck is `editorial`, `mixed`, or image-led. If images could carry meaning, define the first visual anchor before selecting a block type.
10. For image-led work, record the image-text relationship and one human trace per visual scene.

## Candidate directions

Create three directions from different readings of the same facts. A useful default is:

- metaphor-led: a meaningful visual analogy evolves across the deck;
- typographic/editorial: language, scale, pace, and evidence carry the argument;
- diagram/spatial: position, connection, and flow reveal the mechanism.

These labels are not mandatory. Replace them when the content suggests stronger alternatives. Candidates fail when only palette, border radius, or font choice changes.

## Manifest boundary

The manifest is a short design brief that can be shown to the human and an independent reviewer. Do not include hidden chain-of-thought, private data, credentials, or unsupported factual claims. Do not use a polished rationale to excuse a weak render; the visible result must carry the idea.

## Anti-fatigue boundary

The recent-history fingerprint is a prompt for reflection, not a style police. Reuse may be correct when the subject genuinely calls for it. When similarity is warned, explain which repeated choice remains meaningful and what will change elsewhere.

Text-card fatigue is also a perceptual problem. A deck can pass composition-family checks while every page still begins with a headline followed by rectangular information modules. Review what the eye encounters before it reads: image, object, gesture, field note, spatial relation, or only more text. Do not use arbitrary pictures to satisfy a variation quota; change the sensory entry only when the content supports it.
